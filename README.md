# Rancang Perumahan

Alat bantu arsitek dan pengembang perumahan — **dibuat oleh Pindo Tutuko** (Universitas Merdeka Malang, 2026).

1. **Proyek & lahan** — luas, harga tanah, zona batas harga rumah umum, aturan KDB/KLB/KDH/GSB setempat.
2. **Tapak & kavling** — rencana tapak otomatis (jalan utama & lingkungan, deret kavling, RTH, fasum, makam), neraca lahan & PSU, pemeriksaan aturan, kebutuhan sarana, daftar kavling (CSV).
3. **Tipe & desain rumah** — tipe tak terbatas, 7 gaya fasad terkini (modern minimalis, tropis modern, industrial, Skandinavia, Japandi, kontemporer kotak, Nusantara kontemporer), tampak 3D dan denah skematik otomatis.
4. **RAB & kelayakan** — rincian biaya, pendapatan, arus kas bulanan, laba, margin, NPV, IRR, dana puncak, kembali modal.
5. **Pembiayaan & KPR** — kredit konstruksi pengembang (bunga, modal sendiri, IRR ekuitas) dan simulasi KPR pembeli (bunga tetap→mengambang, preset KPR subsidi).
6. **Ringkasan & laporan** — cetak/PDF, simpan/buka proyek (.json), CSV.

Rujukan regulasi yang dipakai (terverifikasi) ada di menu **Sumber & Referensi**, antara lain Kepmen PKP 1722/KPTS/M/2026 dan PP 34/2016.

```bash
npm install && npm test && npm start
```
